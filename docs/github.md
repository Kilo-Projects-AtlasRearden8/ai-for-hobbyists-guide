# Using GitHub for Beginners

GitHub is a free website where people store and share code, documents, and projects. You can use it to save your hobby project notes, scripts, and templates — and to find free tools made by others.

**Remember:** Never put personal info, passwords, API keys, or real data in a GitHub repository. Public repositories can be seen by anyone. See `docs/privacy.md`.

## What GitHub is, simply

Think of GitHub as Google Drive for code and text, with version history. You can:

- Save files online for free
- See every change you made, and go back to an older version
- Share a link to a project with a friend
- Download free tools and templates other people made

## Your first repository (step by step)

1. Go to github.com and create a free account.
2. Click the "+" icon in the top-right, then "New repository."
3. Name it something like `my-hobby-projects`.
4. Choose "Public" or "Private." Private means only you can see it (good while you are learning).
5. Click "Create repository."

## Adding a file

1. On your repository page, click "Add file" → "Create new file."
2. Name it `notes.md`.
3. Type your notes.
4. Click "Commit changes..." at the bottom.

## Finding free hobby tools on GitHub

Search GitHub for things like:
- "Ollama local AI examples"
- "MCP server examples"
- "Python unit converter"
- "knitting pattern generator"

Look for repositories with many stars and a clear `README.md`. Before downloading, check that the license allows your intended use (MIT is common and permissive).

## Safety on GitHub

- Do not upload photos of your home, IDs, or mail.
- Do not paste passwords, API keys, or bank details into any file.
- If a repository asks you to run a script you do not understand, read the README first and ask a knowledgeable friend.
