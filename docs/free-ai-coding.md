# Free AI Coding for Beginners

You do not need to be a programmer, and you do not need to pay, to use AI for small coding tasks. This page shows free ways to write, fix, and understand tiny bits of code for your hobbies.

**Remember:** Never paste personal info, passwords, API keys, or real data into an AI coding tool. See `docs/privacy.md`.

## What AI coding is good for beginners

- Explaining how a small script works, line by line
- Writing a tiny tool to rename files, sort a list, or convert units
- Fixing an error message you do not understand
- Turning a plain-English task into a starter script

## Free options

| Option | What it is | Best for |
|---|---|---|
| Web AI chat (Gemini, Claude, Copilot) | Free AI in your browser | Asking coding questions, getting starter scripts |
| Local AI (Ollama, LM Studio) | Free model on your computer | Private coding help, works offline |
| GitHub Copilot free tier | AI inside code editors | Help while you write code (sign-in required) |

You can start with just a web chat. No installation needed.

## Your first coding task: a unit converter

Suppose you collect yarn by the skein and want to convert yards to meters.

Ask the AI:

> Write a tiny Python program that converts yards to meters. Ask the user for the number of yards, then print the result in meters. Include comments explaining each line. Keep it beginner-friendly.

Copy the code into a file named `convert.py`, then run it:
`python3 convert.py`

## Your second task: a project checklist

Ask:

> Write a simple Python script that lets me add items to a hobby project checklist and save them to a text file. Show me how to run it.

## Rules for safe AI coding

- Never paste API keys, passwords, or real customer data into the chat. Use placeholders like `[YOUR API KEY]`.
- Run code you do not understand in a safe place first — for example, a folder you do not mind deleting.
- AI-written code can have bugs or security issues. Test it on copies, not your only files.
- AI is not a replacement for learning. Use it to explain, not to do everything for you.
