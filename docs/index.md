# AI for Hobbyists — Manual

Welcome. This manual teaches you how to use free AI models for hobbies — crafting, collecting, gaming, and DIY projects — plus related beginner topics, in plain English, step by step.

You do not need to be technical. You do not need to pay for AI. You do need to follow one rule:

> **Never paste personal info into an AI tool.** See [Privacy and Safety](privacy.md) first.

## How to use this manual

1. Start with [Getting Started](getting-started.md) — it shows you how to pick a free AI tool and write your first prompts.
2. Read [Privacy and Safety](privacy.md) before you type anything into an AI chat.
3. Pick a hobby guide:
   - [Crafting](crafting.md) — knitting, sewing, scrapbooking, cards, Cricut
   - [Collecting](collecting.md) — cards, stamps, coins, figurines, vintage
   - [Gaming](gaming.md) — tabletop, video games, online games including FFXIV
   - [DIY](diy.md) — home repair, woodworking, gardening
4. Print the [Project Planner](project-planner.md) and use it for your first project.
