# Project Cost Estimator — Agent Skill

**What it does:** Adds up a list of hobby-project materials and prints a total estimated cost.

**How to use:** Run `python3 project_cost.py`, enter materials as `name, price`, then a blank line to finish.

**Example:**
```
yarn, 12.50
needles, 8.00
stuffing, 4.25
```
Output: `Estimated total: $24.75`

**Safety:**
- Run locally. Do not connect to payment or bank accounts.
- AI prices are estimates — verify real store prices before buying.
- Never paste personal or financial info into an agent.
