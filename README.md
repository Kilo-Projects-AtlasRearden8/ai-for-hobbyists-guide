# AI for Hobbyists

A beginner-friendly manual and static HTML site on using free AI models for hobbies — crafting, collecting, gaming, and DIY projects — written in plain English, step by step, with printable project planners.

## Who this is for

You do not need to be technical. You do not need to pay for AI. This guide is for anyone who wants to use free AI tools for fun projects at home, whether you knit, collect trading cards, play games, or tinker around the house.

## Privacy rule (read first)

**Never paste personal info into an AI tool.** No names, addresses, phone numbers, emails, passwords, bank details, health information, or anything that identifies you or someone else. Treat every AI conversation as public. See `docs/privacy.md`.

## What's inside

- `docs/` — Beginner manuals in Markdown:
  - `getting-started.md` — Picking and using free AI models
  - `privacy.md` — Privacy and safety rules
  - `crafting.md` — AI for knitting, sewing, scrapbooking, and other crafts
  - `collecting.md` — AI for organizing and researching collections
  - `gaming.md` — AI for tabletop and video games (including FFXIV)
  - `diy.md` — AI for home repair and DIY projects
  - `project-planner.md` — Printable AI project planner
- `site/` — Static HTML version of the same manuals (no build step required)
- `LICENSE` — MIT License, Copyright (c) 2026 Asdale Dynamics, LLC

## How to use

Read the Markdown files in `docs/`, or open `site/index.html` in any web browser. Nothing needs to be installed, built, or hosted. All AI model suggestions are free to use.
